# Chat 请求契约缓存（2026-10-31）

Script 调用和域请求现在复用所属模块的输入／输出 schema，避免每次请求重复构造契约字符串。
缓存首次使用时从模块入口元数据生成，随后只做查表和字符串比较；模块卸载时一起释放。
JIT、解释器以及 AOT 域模块适配器使用相同规则。热更新构造新模块和新缓存，旧调用继续保活旧模块。
入口可见性、调用者提交的契约、每次请求的数据包和值仍按原规则检查。

## 归因与范围

优化前使用临时分配探针，按 Script 调用准备、域事务、worker 执行、控制桥、outbox 和 TCP 分段。
另以 schema 生成、布局计算、类型遍历等维度归因；两个维度分别互斥，不能相加。
单连接每条 `say` 约 2753 次 Rust 堆分配（alloc／alloc_zeroed，realloc 另计），
其中 schema 生成约 263 次、布局计算约 278 次；
这两个数字包含各自内部的类型遍历。冻结入口和返回签名克隆各约 1 次，并非主要热点。
因此本轮只缓存不可变契约，不改任务预算、布局、数据传输、调度或浮点保护。

## 性能结果

每格为三个独立进程样本的中位数。吞吐单位为广播/秒；CPU 为每个样本先计算服务端
ms/广播再取中位数。30 个样本均通过消息内容、顺序、扣款和正常退出校验。

| 房间 / worker | 旧吞吐 | 新吞吐 | 变化 | 旧 CPU | 新 CPU |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 / 1 | 856.8 | 831.7 | −2.9% | 1.7900 | 1.8000 |
| 1 / 4 | 1355.4 | 1436.0 | +5.9% | 2.3900 | 2.2638 |
| 4 / 1 | 2123.2 | 2143.3 | +0.9% | 0.8263 | 0.7950 |
| 4 / 4 | 2977.5 | 3025.0 | +1.6% | 1.1517 | 1.1008 |

单房间／四 worker 三轮配对吞吐均提高，范围 1189～1369 → 1407～1461，范围不重叠。
单房间／单 worker 配对为 +3.8%、+0.5%、−12.1%；第三轮新版 P99 为 57.9 ms，未剔除，
该配置没有稳定收益。四房间／四 worker 第三轮基本持平，不能将第一轮的 +26.3% 外推。

单连接吞吐 1843.0→1852.1（+0.5%），P50 **0.4930→0.4749 ms（−3.7%）**，
CPU/请求 **0.451→0.434 ms（−3.8%）**；三轮配对 CPU 均下降。
P99 0.7435→0.8035 ms，不能宣称尾延迟改善。延迟包含完整请求／回显路径。
样本量有限，本轮支持减少固定请求成本，不支持所有配置全面提速，也未重测 Tokio。

## 独立分配复测

单连接分别运行 0／500 条消息窗口，预热后开始计数，扣除零消息窗口再按广播条数归一化。
新旧使用同一套探针和相同 chat 源码，每版两个窗口都通过协议校验；这是一次计数复测，非统计计时。

| 每条消息 | 旧版 | 新版 | 减少 |
| --- | ---: | ---: | ---: |
| alloc／alloc_zeroed 次数 | 2753.37 | 2645.40 | 3.9% |
| realloc 次数 | 368.01 | 246.01 | 33.2% |

Script poll 阶段约少 108 次分配。其他路径仍会生成 schema，因此没有消除最初归因的全部 263 次。
类型布局、预算准入、Buffer 申请和复制计数未随之下降；不能将分配次数减少等同于同幅 CPU 改善。
缓存的代价是契约字符串随模块保留到卸载。
全部临时探针已移除，源文件恢复后逐文件核对 SHA-256；Release 工具和运行时恢复为正常优化版。

## 方法与验证

沿用[上一轮](chat-integer-fp-2026-10-31.md)的工作负载与测量口径：Apple M1 Pro、16 GiB、
macOS 26.6.2 ARM64、Rust 1.99.0，Cranelift 0.137.1、`speed`，工具和运行时使用 Rust Release。
16 客户端、64 字节正文、1／4 房间 × 1／4 worker，每客户端预热 25 条、每批 250 条、至少 3 秒；
单客户端每批 5000 条。三轮旧→新、新→旧、旧→新交替，第二轮房间／worker 顺序倒置。
计时期间不运行构建、测试或探针；计数使用独立产物，不能当作计时证据。

旧产物复用上一轮优化后的工具和应用，构建身份为 `63a2703` 加纯整数浮点保护补丁，
与 `e0f5b86` 的运行时实现一致；新产物基于 `e0f5b86` 加本次改动。
原始数据、探针、工具快照、源码补丁和日志保存在 `target/benchmarks/chat-alloc-phases/`，不提交 Git。

7 项 Script 契约测试、1 项 Script bridge 热更新／取消测试和 chat 串行／并行两项真实 TCP
测试通过，执行覆盖 JIT、解释器和 AOT。新增回归验证同名结构体变更契约、失败加载保留当前模块、
旧调用跨更新完成，以及缓存命中后仍拒绝非法值和错误输出契约。
`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings` 通过；未运行全量检查或压力穷举。
