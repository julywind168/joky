## 注释

```joky
// 行注释
/* 块注释，支持嵌套 /* inner */ */
```

`///` 是函数文档注释，`//!` 是文件或模块文档注释。

## 绑定

表达式之间可以使用换行或 `;` 分隔，`;` 不是强制的。块中非末尾的表达式必须是
`Unit`（`let`、赋值、`println`、副作用 `for` 等）。未使用的值用 `let _` 显式丢弃，
例如 `let _ = add(1, 2)`。`echo value` 除外：它只观察，不消费绑定。

`let` 是表达式，创建不可变绑定并返回 `Unit`。允许用新的 `let` 遮蔽同名绑定：

```joky
let x = 100
let x = 200
x
```

绑定类型默认从初始值推导，也可以显式标注：

```joky
let msg: String = "hello";
let count: Int32 = 0;
```

局部 `var` 创建可重新赋值的绑定；声明和赋值都返回 `Unit`。必须提供初始值，
类型在声明时固定。`let` 与 `var` 可以互相遮蔽，参数仍不可变：

```joky
var count = 0
while count < 3 { count = count + 1 }
var text: String = "ready"
text = text + "!"
```

赋值先完整求右值，再释放仍由原绑定持有的旧值并接收新值。允许 `x = x`，
也允许移出后重新赋值；重新初始化前不能读取或借用。可达分支或循环路径的
初始化状态必须一致，即使合流后直接退出作用域也一样。

普通块、顺序循环和 `when` 可以修改外层 `var`。普通闭包、任务、并发 `for`、
handler arm 和 `do` body 不能直接捕获外层 `var`；`move fn` 可以消费绑定并将
其状态保存到闭包中，连续调用保留修改。即使是 Copy / Shared 值，捕获后的外层
绑定也须重新赋值才能再用；重新赋值不影响闭包。可变捕获闭包不能实际挂起。
各边界内部可以声明自己的 `var`。需要快照时在边界外写 `let snapshot = value`，
跨任务共享状态使用 Cown。模块级 `var`、可变参数、struct 可变字段和类型值
`var` 均不支持。

## 元组解构

`let` 和 `var` 支持嵌套元组与 `_`：

```joky
let (reader, writer) = pair
let (first, (_, last)) = nested
var (x, y) = (0, 0)
x = x + 1
```

右值只求值一次；唯一资源按字段转移所有权，`_` 负责释放对应值。
`var` 使模式中的所有命名绑定可赋值。绑定名称不得重复，元组长度必须匹配。
只支持不可失败的元组、名称和通配符模式；枚举模式使用 `match`。

## 元组

元组是固定长度、异构的值类型。元组字段使用从 `0` 开始的下标访问；单元素元组需要尾逗号：

```joky
let pair: (Int32, String) = (1, "hello")
let first = pair.0
let single = (42,)
```

元组和函数参数均为不可变值；元组字段不能赋值。

值聚合可以包含 class。只要 tuple、struct 或 enum 递归包含 class，该值就会成为 move-only；读取方法可以临时借用它，消费后原绑定不可再使用。

## 条件表达式

`if` 是表达式，条件必须是 `Bool`，`else` 分支必须存在且与 then 分支类型相同：

```joky
let x = if true 1 else 2
```

布尔类型为 `Bool`。整数类型为 `Int8`、`Int16`、`Int32`、`Int64`、`UInt8`、`UInt16`、`UInt32`、`UInt64`，浮点类型为 `Float32`、`Float64`。整数字面值默认推导为 `Int32`，浮点字面值默认推导为 `Float64`。

`if`、`match`、调用等前缀形式的嵌套深度上限为 64；超出时编译器给出
`expression nesting exceeds 64`，而不是在编译期栈溢出。`a + b + c + …`
这类左结合运算符链按迭代处理，可以长于该限制。

## 算术与位运算

算术和位运算要求两侧同一种数值类型，不隐式转换。`+`、`-`、`*`、`/`、`%` 接受整数和浮点；`<<`、`>>`、`&`、`^`、`|`、`~` 只接受整数。优先级从高到低为 `* / %`、`+ -`、`<< >>`、`&`、`^`、`|`、范围、`&&`、比较和 `||`。一元 `-`、`!`、`~` 与乘除同级绑定。

```joky
let remainder = 10 % 3
let shifted = -8 >> 1
let bits = 6 & 3 | 1
let inverted = ~0
```

整数 `/` 和 `%` 向零截断，余数符号跟被除数。常量整数除数 `0` 在编译期报错。浮点 `%` 同样向零截断，符号跟被除数。有符号 `>>` 是算术右移，无符号是逻辑右移；移位量先按位宽取模。`~` 按位取反。

`&` 在类型和参数位置仍是借用，例如 `&self` 和 `value: &String`。`&&`、`||` 仍是逻辑运算。前缀 `|...|` 是闭包；表达式后面的 `|` 只有在配对的 `|` 之后紧跟 `{` 或 `->` 时才是尾随闭包，因此 `a | b` 是按位或，`f |x| { x }` 仍是尾随闭包。`parallel` 和 `race` 的臂在裸 `|` 处结束，臂里的按位或写成 `(a | b)`。

范围端点按加减的优先级解析，所以 `a .. b & c` 是 `(a .. b) & c`，`a & b .. c` 是 `(a & b) .. c`。位运算和范围混写时加括号。

整数字面量可以写 `0x`、`0b`、`0o`，整数和浮点都可以用 `_` 分隔。不加 `42i64` 这类后缀，类型仍靠推断。时间字面量保持十进制。

已经能赋值的位置可以复合赋值，结果是 `Unit`：`+= -= *= /= %= <<= >>= &= ^= |=`。位置只求值一次。`&&=` 和 `||=` 不支持。

绝对值和最值使用数值方法：`n.abs()`、`a.min(b)`、`a.max(b)` 两侧同类型。无符号 `abs` 原样返回。有符号最小值的 `abs` 在常量上编译报错，运行时 panic。浮点只要有一边是 NaN，`min` 和 `max` 的结果就是 NaN。

## 数值转换

`as`、`as?`、`as%`、`as|` 把整数转换为目标整数类型，按后缀绑定，优先级高于所有二元运算和前缀一元运算；转换负数时写 `(-x) as| UInt32`。四种形式按"目标值域是否包含源值域"静态判定：无损组合（相同类型、同符号加宽、无符号到更宽的有符号）只允许 `as`；有损组合（收窄、有损的跨符号转换）用 `as` 直接编译报错。

```joky
let wide: UInt64 = byte as UInt64        // 无损：只允许 as
let low: UInt8 = (wide & 255) as% UInt8  // 有损：明确要低位，补码回绕
let byte: Result(UInt8, String) = wide as? UInt8
let capped: Int8 = 300 as| Int8          // 127：夹到目标上界
let floor: UInt8 = (-1) as| UInt8        // 0：夹到目标下界
```

`as?` 产出 `Result(目标类型, String)`，越界为 `Err("integer value out of range for …")`，可与 `?` 传播；`(x as? UInt8)!` 是断言形式，越界即 panic。`as%` 保留补码低位后按目标符号解释，`(-1) as% UInt32` 得到 `4294967295`。

`as|` 直接产出目标类型：低于目标最小值时取最小值，高于目标最大值时取最大值，目标闭区间内保持原值。先按源类型的数学值夹到边界，再转换位宽和符号；例如 `(-200) as| Int8` 得到 `-128`，`300 as| UInt8` 得到 `255`，`UInt64` 的最大值转为 `Int64` 时得到 `9223372036854775807`。操作数只求值一次。

无损组合写 `as?` / `as%` / `as|`、有损组合写 `as` 都在编译期报错。数值 `.to()` 已移除；目前四种转换均只支持整数，浮点参与的转换暂不支持。

## 比较与逻辑运算

比较表达式 `==`、`!=`、`<`、`<=`、`>`、`>=` 返回 `Bool`。比较两侧必须同类型；等值比较要求 `PartialEq`，有序比较要求 `PartialOrd`：

```joky
let ready = count >= 3
```

逻辑运算使用 `!`、`&&`、`||`，只接受 `Bool`。`&&` 和 `||` 会短路求值，优先级从高到低为 `!`、`&&`、`||`：

```joky
let visible = !hidden && (ready || has_override)
```
