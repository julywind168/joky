# 状态域语法糖草案

状态：2026-10-16，A0–A4 与 W0–W4 已实现。`when` 统一访问 1–64 个域，
支持可选字符串标签、独立纯值捕获／结果、受检拥有状态及兼容晚绑定；`#state` 与句柄方法调用也已接入。
具名块跨版本检查兼容性，匿名块只匹配原模块编译版本。拥有型载荷、周期／迁移声明仍为后续工作。
正式语法见[语言参考](language.md#when-状态域操作)；本文保留设计依据和实施记录。
本文 `text` 代码块为业务示意，不作为独立可执行程序。

本草案负责 API 收敛、业务写法、语义选择与实施阶段。已有 API 见[语言参考](language.md#内置域访问-jokydomain)，
状态及任务边界见[并发设计](server-concurrency.md)，发布与迁移协议见[热更新计划](aot-script-hot-reload.md)。
实现后将正式语法归入 `language.md`，运行时及 ABI 不变量归入 `architecture.md`。

## 1 现有基础与目标

已有单域读写、双域联合短操作、最多 64 域的集合快照与候选原子提交，以及具名操作的兼容晚绑定。
Rust 宿主已有 2–64 域短操作入口；Joky 源码的 `when` 已统一支持 1–64 域，
旧具名直接 API 保留单域和双域形式。执行仍由同一宿主驱动的单线程 FIFO 推进，没有并行读执行或 CPU 抢占。

单域、多域及集合快照均支持经过资格检查的嵌套记录、String、Array/Map 等拥有图。
具名单／双域短操作已支持有界嵌套纯值记录输入和结果，复用 HR7 Script 契约的资格限制。
快照投影、构造输入、异步请求输入／结果及 Timer 输入已支持同一纯值记录契约；
拥有型输入与结果尚未开放。

语法糖的目标是减少独立操作函数、权限接线和参数打包代码，保持状态归属、取消、错误隔离及
热更新规则可见。不增加 Service 生命周期，不创建模块可变全局状态，也不把短操作解释为事务。

| 写法 | 目标 | 优先级 |
| --- | --- | --- |
| `when` | 内联编写 1–64 域受检短操作，具名块兼容发布后执行新版实现 | 已实现 |
| `#state` | 在类型声明处检查域根资格 | 已实现 |
| `handle.method(...)` | 单域方法调用、纯值参数打包、具名晚绑定 | 已实现 |
| 候选编辑流程 | 从冻结状态派生、修改候选，再验证并原子发布 | A4 已实现显式 edit_snapshot／edit_candidate API |
| 周期与迁移声明 | 简化已有 Timer 和迁移入口的接线 | 后续，不混入 when 首版 |

### 1.1 公共 API 收敛契约

现有单域、双域、集合 API 的能力差异应逐步收敛；安全边界继续沿用独占 Owner、非保活句柄、
完整读取依赖验证、无挂起短操作、失败隔离和有界资源。先统一契约，再接入语法糖。
本节的“目标”均须单独实现和验收；不得用文档更新代替实现或声称已有行为发生变化。

**访问错误。** 具名短操作与未来 `when` 共用第 5 节的访问错误协议。执行前的关闭、隔离、
权限／别名不合法、入口或签名不兼容、资源准入不足可通过 Result 处理；这些拒绝必须保证
没有执行操作体。调用方求值失败及操作体内运行时失败仍沿任务失败通道传播，写失败隔离
全部声明可写的域，不回滚，也不伪装成可以安全重试的准入拒绝。异步请求仍有独立任务失败
和取消结果，不与短操作错误机械合并。具名短操作已采用此协议，现有调用方已迁移。

**候选冲突。** 数据、代码或 schema 变化导致原计算过期，目标协议统一归为 Conflict；
InvalidAccess 留给错误执行器、目标身份、权限等访问问题。不因变化发生在写目标或只读依赖
而改变分类。Closed、DomainFailed、Cancelled、Expired 仍有各自终态，终态确定后不改写。
代码变化不允许旧候选套用新实现后直接提交；重算必须重新获取完整快照，由业务决定是否重做
外部工作，不自动重放网络或其他副作用。写目标与只读依赖已采用相同的版本冲突分类。

**输入与结果。** 统一复用具名短操作已有的有界纯值记录契约：标量与嵌套普通非泛型记录，
总字段数 64、记录深度 8，完整名义字段契约参与跨版本校验。按入口扩展构造输入、快照结果、
候选输入、异步请求输入／结果及 Timer 输入；每处都须覆盖输入复制、结果预留、清理及预算。
`create` 与单域、双域、集合候选的纯值记录输入已实现，复用原同步构造和资源清理协议；
构造仍绑定调用流程模块，候选保留完整原始读取依赖。
单域、联合快照及集合冻结投影已支持纯值记录结果；结果独立复制，捕获时的版本凭据保持不变。
`request/request_read` 已支持纯值记录输入／结果，沿用独立任务、权限、版本绑定及清理后交付协议。
`after/every` 已支持纯值记录输入，登记后保存独立值，周期调用复用该值，每次执行仍校验当前代码契约。
带输入只读查询已实现：`query/query_from` 使用 `fn(&S, A) -> R`，`query_pair` 使用
`fn(&S, &T, A) -> R`；保留无输入的 `read/read_from/read_pair`。查询支持上述纯值输入与结果，
不授予写权限、不推进数据修订，沿用 A1 访问错误。String、容器、业务枚举和其他
拥有型消息不随此项自动开放；状态根资格也不因载荷扩展而放宽。

**实现归属。** 本轮保留首域当前模块提供具名联合操作实现的规则，不新增独立操作所有者。
首域是显式的主域，即使只读也决定实现来源；其他域仅提供与参数契约兼容的状态。顺序必须
保留在操作契约中，调度排序或集合去重不能偷偷更换主域。诊断应区分“主域缺少／不兼容入口”
和“参与域状态不兼容”，并标明相关操作与参数位置。此规则同样约束未来 `when`；快照和已计算
候选继续验证原版本，不因此获得晚绑定重算。修改此规则需另立版本归属设计。

**快照与提交。** 候选流程已显式选择目标并提供写能力，不从联合快照的位置隐式选择
第二个写目标；始终保留全部读取依赖，不提供拆分或拼接分时凭据的接口。三种回执已共用
CommitError、等待、取消与同名 with_outbox 消息附加协议，成功报告仍保留每个确切写目标的
新修订。集合修订查询已返回 Result<Option<UInt64>,RevisionError>，
区分未完成、提交失败和非写目标，不再使用 0 哨兵。投影结果快照与冻结根
快照具有不同复制成本，不能为统一 API 而强制所有操作复制完整状态。冻结候选编辑已按 A4 实现，见语言参考。

**取消与本地能力。** 回执拥有尚未发布的提交；取消等待分支不等于取消提交，丢弃回执或
显式取消才撤销待执行提交，发布后的状态不回滚。若增加“提交并等待”便利入口，其内部回执
随调用者取消清理，并明确发布前／后的区别。命名逐步统一写能力、候选、提交和消息附加操作；
`read_only` 已同步化，只收窄能力；保存值读取仍需资源租借及结果包预算，保留 `@suspends`。

## 2 when 写法与状态访问

标签可选，使用普通字符串字面量；`"transfer"` 是稳定操作标签，不是另一份函数定义：

```text
let amount = 10
let outcome = when "transfer" (mut source, mut target, rules) {
    if amount <= 0 || amount > rules.maximum || source.balance < amount {
        false
    } else {
        source.balance = source.balance - amount
        target.balance = target.balance + amount
        true
    }
}
```

外部三个名字是域句柄；块内同名名字分别表示对状态的可写或只读访问。`amount` 是独立捕获值。
先完成业务检查再修改；示例不表示溢出等运行时失败会回滚。

`when` 只在具名非泛型 `@suspends` 流程中使用，作为上下文关键字识别。访问项只接受已有句柄
绑定名，复杂查找先在外部完成，不提供可能重复求值的访问项表达式。普通同名调用与块相邻时需要括号消歧。

- 一个访问列表包含 1–64 个绑定位置，因此不同域数也不超过 64；第 65 项在编译时拒绝。
- `mut` 要求写句柄；无 `mut` 只授予读权限，即使外部持有写句柄也不能在块中写入。
- 同一域重复只读可归一化调度，保留各参数绑定；任何包含可写参数的同域别名在执行前拒绝。
- 全部域须属于当前执行器。权限不能由记录字段、整数或语法糖伪造。
- 一次申请覆盖完整访问集合，不逐域持权等待。块体同步执行，其他域操作不会插入其中。

单域 `when "read_score" (player) { player.score }` 与多域采用同一语义，不分别设计关键字。
初期实现可从单域开始，但不能把双域数量限制固化进语法和隐藏操作契约。

## 3 块体 捕获与返回

编译器把块体提取为带域引用参数和独立捕获包的隐藏操作，沿用 `domain_entry` 的同步、
无外部效果和不逃逸证明；检查整个可达调用链，而非只检查块内有没有 `@suspends`。

块体不能挂起、调用网络或宿主函数，不能再次申请域访问或嵌套 `when`。
域引用、容器借用和视图不能作为结果或保存到外部。普通受检辅助函数及域状态内部的合法
容器操作可以使用，临时存储仍受状态峰值预算约束。

首版捕获与业务结果 R 支持标量和有界嵌套纯值记录，复用 HR7 的资格规则：
总字段数最多 64、记录深度最多 8，Unit 和空记录字段也计数。多个捕获合成一个外层记录，
共同计入上限；不按每个捕获分别获得完整额度。捕获按值复制，不能借用、移入拥有资源或保存函数值。
实现需扩展域操作打包与校验，不能仅因 Script 桥已支持就跳过三后端验证。

捕获在入队前固定，排队期间不观察外部变量后续变化。普通局部赋值只修改操作内部副本，
需要影响外层流程的数据通过结果返回。捕获的句柄不能绕过访问集合在块内追加域操作。

块末尾表达式产生 R。首版禁止块内 `return` 和闭包；`break`、`continue` 只能作用于
块内定义的循环，不能跨边界。业务枚举、拥有型捕获和拥有型结果留待后续资格及清理协议设计。

## 4 稳定操作身份与兼容热更新

具名 `when` 是可晚绑定的域操作，不能提取成固定指针闭包。排队项保存稳定操作身份、
访问契约、域句柄及独立捕获值，在实际执行前解析当前实现。旧流程提供旧时刻的输入，
兼容的新块体处理这些输入；不会重新执行旧流程的网络查询、条件判断或捕获表达式。

### 4.1 显式身份与匿名形式

具名形式用逻辑模块路径、外层具名函数限定名和解码后的标签组成操作键。
标签是非空普通字符串字面量，允许空格和 Unicode，区分大小写，不支持插值。重复标签在同一所属函数中报错；同一标签位于循环中，每次迭代
是同一个操作的新调用。泛型和局部匿名函数中的操作身份先不开放，另行确定实例身份规则。

标签不能取自行号、块序号或源码哈希。移动源码行、插入其他操作、修改算法不应改变身份；
重命名模块、所属函数或标签则视为删除旧入口并新增入口，除非未来显式提供身份别名。
删除后不得把旧身份复用于语义无关但 ABI 相同的操作；编译器的兼容检查不能证明业务语义相同。

匿名 `when (...) { ... }` 已实现。它只匹配同一编译模块；提供实现的模块替换后，
旧请求返回 Incompatible，不凭位置猜测新版块，也不固定旧代码继续运行。AOT 可直接使用匿名形式。
入口逻辑名默认 main，宿主可通过 AST 的 logical_name 显式指定；导入模块使用规范 import 路径。
物理文件名、诊断源码名及临时路径不参与身份。

### 4.2 实现归属与契约

沿用现有多域具名操作方向：第一个参与域的当前模块决定操作实现，其余域逐一检查兼容性。
访问顺序因此是契约的一部分，不允许运行时为了排序而改变实现归属。
隐藏操作须导出到该业务模块的内部操作表；普通公开函数名称不能冒充隐藏操作身份。

块体必须编译在能为该域提供实现的模块中。AOT 中的块不会自动被搬到 Script 模块；
AOT 宿主应调用 Script 业务入口，让业务模块拥有可热更新的操作。AOT 自有域仍可使用原生操作，
但此语法不赋予 AOT 二进制自我热替换能力。

准入及实际执行前都校验：操作键、域参数数量与顺序、逐项读写权限、状态结构契约、
捕获字段名／顺序／类型、结果契约，以及同步、无宿主效果、不逃逸的证明。
捕获字段名取词法绑定名，按名称排序；重命名视为不兼容，改变首次使用顺序不会改变契约。
内部操作表沿用 v3 名称／类型编码；隐藏键使用不可由源码声明的前缀、长度分隔及标签字节编码，
不靠机器地址或本次编译的名义 ID 判定具名操作跨版本兼容。

| 发布变化 | 排队或旧流程后续发出的 when |
| --- | --- |
| 同一身份和契约，只修改块内算法 | 执行当前域绑定的新版实现 |
| 等待期间多次兼容发布 | 实际执行前解析当时的当前实现 |
| 捕获、返回值、访问权限或状态契约不兼容 | 执行前拒绝，不执行旧实现作为兜底 |
| 操作身份被删除或改名 | 执行前拒绝，不按相似源码匹配 |
| 已经开始执行块体 | 同步运行结束，发布在执行器后续处理 |

不要求数据修订或代码版本仍等于入队时的值：`when` 操作的是执行时的活状态，兼容代码发布
本身不构成冲突。它与快照候选不同，后者仍须验证原读取凭据，不能因为支持晚绑定就放宽。
各域不必绑定同一个模块版本，但每个参与域都必须满足当前选定操作的对应契约。

操作表和排队记录需保留必要的旧契约及结果解码元数据，但不能以此固定执行旧块体。
解析后须保活实际执行模块直到操作结束，调用方用原契约接收结果；这些生命周期需要新增验收。
布局兼容不保证业务兼容，发布者仍负责判断新版逻辑能否处理旧流程传来的值。

## 5 错误 取消与资源

首版 `when` 复用具名短操作已有的 `Result<R, DomainAccessError>`。上例的 R 是 Bool，
`Ok(false)` 表示业务拒绝，不能与运行时拒绝访问混淆。已有错误分类如下：

| 错误 | 发生条件 |
| --- | --- |
| Closed | 任一参与域已关闭、正在关闭，或源码句柄在当前执行器不可用 |
| DomainFailed | 任一参与域已被隔离 |
| InvalidAccess | 所属请求上下文、权限或可写别名不合法 |
| Incompatible | 操作缺失，或当前操作与调用契约不兼容 |
| ResourceLimit | 受理额度或预留存储不足，且尚未开始执行块体 |

此 Result 外层是调度协议，不要求先开放任意业务枚举结果。句柄及捕获表达式在入队前求值时
发生的错误仍属于调用流程错误，包括调用方捕获包分配失败。捕获包、结果空间和队列资源在执行前准备好；块体中的分配
或其他运行时失败走既有任务失败通道，不能伪装成上述表示“没有执行块体”的 Err。

直接修改不提供失败回滚。正常返回 false 也不撤销写入，所有声明可写的域正常完成后推进修订。
块体运行时失败按现有协议隔离全部声明可写域，只读域和无关域保持可用。
需要任何失败都保留全部旧根时，使用独立候选与原子提交。

调用者取消时撤销尚未执行的申请并释放捕获。取消调用者本身不保证还能收到一个 Cancelled 结果。
已经完成的写入不因等待者取消、结果丢弃或后续关闭撤销；执行中的同步块没有中途抢占取消。
旧结果及捕获在取消、关闭、失败、热更新交错下只能清理一次，并持续按现有配额计费。

## 6 状态声明与句柄方法调用

```text
#state
struct Room { count: Int32 }

impl Room {
    fn count(&self) -> Int32 { self.count }
    fn add(&mut self, amount: Int32) -> Int32 {
        self.count = self.count + amount
        self.count
    }
}
```

`#state` 在声明处检查域根资格，复用已有字段图、清理和预算限制；不自动创建域，不改变
Owner 归属，也不将状态放进模块全局变量。没有属性但满足资格的现有普通记录仍能创建域。
属性不代表全部方法自动合格：域入口仍需逐个通过效果和不逃逸检查。

`room.add(amount)` 根据接收者为域句柄解析为单域具名调用，在 `@suspends` 流程中等待，
与 `when` 使用一致的访问错误协议。普通 Room 值或块内状态引用上的方法仍是同步方法调用。
多个参数按独立纯值包传递，方法身份来自类型及方法限定名，执行前按同一契约规则晚绑定。

Owner 已有 `close`，写句柄已有 `read_only` 等能力 API；句柄自身固有方法和可见 trait 方法优先，
状态方法被遮蔽时通过 `when` 显式访问。首版仅转发非泛型固有方法，要求共享或可写借用接收者；
不转发状态 trait 方法、泛型方法或按值接收者。只读句柄不能调用可写方法，同步代码不能隐式驱动执行器。

## 7 候选流程与其他语法糖

`when` 不会自动创建快照，也不会复制整个状态来实现回滚。候选路径继续采用
“联合快照 → 独立候选 → 完整依赖验证 → 原子发布”。A4 已提供冻结拥有图、消费式局部编辑、
可跨挂起分步选择目标的候选包和多域拥有存储转移。后续仍需处理：

- 若引入分块复制或写时复制，须维持现有峰值计费与唯一清理；当前冻结采用完整深复制。
- 拥有型输入／投影及候选编辑语法糖；现有纯值组合输入和分步编辑不授予 HR5 分步迁移能力。
- 更高层的业务重算策略；配置等额外依赖仍须显式登记，冲突不自动无限重试。

这些涉及存储和所有权；显式编辑 API 的失败沿现有任务失败通道传播，语法糖另立切片，
不在本草案承诺通用事务、自动依赖追踪或字段粒度冲突检测。

出站信箱的便捷写法仍须保留提交绑定及满队列整次拒绝的边界。普通 `when` 内不能直接发送
网络消息，也不因正常返回就自动获得候选信箱的提交协议。该协议保证内存提交与入队，
不保证 TCP 已送达或崩溃后仍可恢复。

`#every` 未来只简化显式 Timer 注册，必须保留宿主所有者和取消控制，不能在模块加载时
偷偷启动永久任务。迁移声明只简化已有显式 prepare/step/publish 流程，不能由 `#state`
自动猜测结构迁移。Service 关键字、配置快照与隐式 Context 注入均不纳入本轮。

单域、双域和请求内访问已通过三后端测试；AOT 宿主 × 两种 Script 后端已验收兼容晚绑定，
