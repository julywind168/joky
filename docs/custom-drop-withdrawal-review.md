# 自定义 Drop 撤回与迁移

2026-11-10：撤回编译器认可的 `joky/drop.Drop` 及自动调用用户析构的语义。
本次不移除自动所有权清理，也不移除 runtime、宿主或 Godot 适配器中的 Rust Drop。
当前规则见[自动清理与显式生命周期](language.md#自动清理与显式生命周期)。

## 决策依据与范围

Joky 面向游戏后端、引擎及 host + script 场景。仓库内 std 的实际实现不依赖用户 Drop；
系统资源已由受检资源所有权和宿主 stop/release 协议回收。任意用户析构带来的失败、重入、
执行预算和跨 worker 调度成本，缺少当前 std 的实际需求支撑。

删除的能力是“离开作用域时隐式执行用户 Joky 代码”。保留：

- String、容器、拥有记录、枚举、元组与闭包捕获的自动清理，包括部分构造、提前退出、失败和取消。
- 移动时转移清理责任，覆盖和元素删除时释放旧值；`mem.drop`、replace、swap。
- 宿主资源的恰好一次 release、所属线程、stop 先于借用来源释放、代码与模块保活。
- 持久实例关闭、任务排空和旧模块使用期间的生命周期保证。

不引入 defer、析构闭包或新的隐式业务生命周期回调。

## 实现变更

| 层次 | 变更与保留责任 |
| --- | --- |
| 导入与 trait | 删除内嵌 drop.jk 和专用 trait 身份。旧 `joky/drop` 导入明确报错；用户自行声明的同名 trait 按普通接口处理 |
| 类型布局 | 删除 custom_drop 与 drop_anchor。泛型记录按实例化字段判断 Copy 和拥有布局，不再添加仅服务用户析构的隐藏 Buffer 槽 |
| IR 与字段操作 | 删除 DropHook、析构专用函数效果与字段移出限制；保留普通清理登记、部分初始化和所有权交接。字段移出仍消费整个原记录，不开放可继续使用原记录的一般部分移出 |
| JIT、解释器、AOT | 删除用户析构入口、回调地址、实例 hook 表及仅服务用户回调的快照；普通 owner 描述、资源清理和 CPS 生命周期继续共用 |
| runtime 与容器 | 清理条目和元素描述只保留拥有槽及布局。普通 Buffer 树仍迭代释放，不增加原生递归或释放时的工作栈分配 |
| 并行执行 | 删除携带用户析构代码的 portable 描述与专用 worker 清理回执；保留任务终止、读者排空、未领取结果清理、预算归还及代码保活 |
| 持久实例 | 根描述保留拥有偏移；关闭、失败和转移错误继续释放根与临时存储。现有公开清理报告 API 保留，不在本次另作 API 删除 |

这改变了编译器私有布局和内嵌镜像。源码、标准库镜像与生成产物需要用同一版本重新构建，
不能混用旧生成代码与新 runtime。没有根据本次删除量推断性能收益。

## 业务迁移

仅用于释放 String、容器或内置资源的包装记录，删除用户 Drop 实现即可，保留原字段。
依赖隐式日志、计数、节点修改、提交或回滚的代码，需要把动作移到显式业务结束点。
显式方法可以等待或返回业务错误；失败或取消时仍自动释放底层资源，但不保证执行业务副作用。

自定义宿主句柄可使用[受检资源 ABI](../include/joky_resource.h)，前提是 release 同步、不可失败、
不可访问 Joky 数据，并遵守线程和代码保活约束。不能机械地把任意旧析构体搬到 release。
只靠 Drop 维持非 Copy 身份的泛型实例需要重新审视：唯一责任应由实际拥有字段或资源表达。

`Drop` 不是保留关键字。自定义同名 trait 不会自动执行；旧内置导入的迁移错误避免了旧代码静默丢失析构行为。

## Godot

撤回前，`async_drop.jk` 与 `async_detach.jk` 在 State 析构时把节点改名为 Dropped／StateDropped。
这些演示行为已删除；测试改为验证实例和任务计数归零、信号断开、detach 不重复执行及原始失败诊断。
适配器自身的 Rust Session 关闭、连接解绑和上下文恢复继续保留。

`_exit_tree` 可承接节点退出树时的业务动作，但不能覆盖“节点仍活着、脚本已失败或被 detach”的所有路径。
宿主生命周期管理继续负责这些清理，不通过新的隐式 Joky 回调补偿。

## 测试迁移与验收

原有许多测试把用户析构事件当作存储释放的观测。迁移后：

- 普通容器、借用、挂起与实例测试保留结果、显式求值顺序、存活分配、调用/持久预算、失败及取消检查。
- [宿主资源用例](../tests/fixtures/resource_owners.jk) 验证字段移出、替换、嵌套容器、闭包捕获、部分构造、取消与实例关闭的真实 release。
- [Map 独立模型](../tests/fixtures/map_stress.jk) 和 [FixedArray 模型](../tests/fixtures/fixed_array_f5.jk) 使用宿主资源释放计数，保留重复释放和缺失释放检查。
- [栈保护用例](../src/backends/aot/tests/stack_probe.rs) 改用宿主资源 release 验证拒绝深递归后的释放与线程复用。Drop 撤回验收时它仍是测试原型；后续同步生产接入和覆盖边界见[当前架构说明](architecture.md#k1-3-原生栈保护提案)。
- 旧导入拒绝、失败后已加载模块仍可用，以及同名普通 trait 独立验证。
- 删除只验证用户析构执行顺序、析构失败、独立指令预算或析构重入的用例；不再宣称这些行为受支持。

- Godot 适配器格式、Clippy、10 项 Rust 测试及 Debug 构建通过；真实 Godot 4.7.2 场景全部通过。脚本失败与重入 detach 的迁移断言已验证，网络背压测试内遗留的旧 join 分隔语法同步修正。
